## Description

```
Notify is a lightweight, native iOS client for ntfy — the simple,
open-source pub-sub notification service. Manage your topics, publish
messages, and browse message history, all in a clean, fully offline-capable
interface.

Works with any ntfy server: the free public ntfy.sh, or your own
self-hosted instance, with optional username and password authentication.

FEATURES

• Save and organize the topics you follow
• Live message streaming while you're viewing a topic
• On-device message history that persists even after it expires on the
  server
• Pin important messages for quick access from a dedicated Pinned tab
• Swipe to delete messages or entire topics
• Compose and send messages with a custom title and priority
• Available in 10 languages: English, Spanish, French, German, Italian,
  Portuguese, Japanese, Chinese (Simplified), Russian, and Arabic

PRIVACY BY DESIGN

Notify collects no analytics and requires no account. Your server address,
credentials, and message history stay on your device — the app only talks
to the ntfy server you choose to connect to.

ntfy is an independent open-source project and is not affiliated with this
app. Learn more at ntfy.sh.
```
